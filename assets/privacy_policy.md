# プライバシーポリシー

制定日:2026年11月15日

「あなたの軌跡」(以下「本アプリ」)の開発者(以下「開発者」)は、本アプリで扱う情報について、次のとおり定めます。

## 1. 基本的な考え方

- 日記・ひとこと・行動履歴・写真などは、あなたの端末の中に保存します。
- これらの情報は、あなたが操作したときにだけ、必要な範囲で、外部のサービスに送ります。送るのは、次の「4. AIサービスへの送信」「5. 開発者のサーバーに保存する情報」「6. そのほかの外部サービス」に書いたものだけです。
- 取得した情報を、販売したり、広告の目的で第三者に渡したりしません。

## 2. 端末の中に保存する情報

次の情報は、あなたの端末の中に保存します。開発者のサーバーには、自動では送りません。

- 日記、ひとこと
- 行動履歴(位置情報から作った、滞在した場所や移動の記録)
- 日記に使うXの投稿(Xから共有した投稿、Xのアーカイブから取り込んだ投稿)
- アプリの設定、使い方の説明を見たかどうかの記録

アプリを削除すると、これらの情報は端末から消えます。バックアップをとっていない場合は、元に戻せません。

## 3. 端末から取得する情報と、使いみち

本アプリは、あなたの許可を得て、次の情報を使います。許可は、端末の設定から、いつでも取り消せます。

- **位置情報**:行動履歴を記録するために使います。記録をオンにしている間は、アプリを閉じていても、バックグラウンドで取得します。記録は、設定でオフにできます。
- **写真**:日記に使う写真を選ぶために、端末の写真を読み取ります。撮影日時などの情報も使います。
- **通知**:返信のお知らせや、過去のポスト(ツイート)のお知らせを表示するために使います。

## 4. AIサービスへの送信

日記を書いてもらうときや、日記の振り返りを作成するときに、あなたが選んだ材料を、AIのサービスに送ります。送るのは、「AIに日記を書いてもらう」「振り返りを作成する」を実行したときだけです。送った内容は、開発者のサーバー(Amazon Web Services)を経由して、AIのサービスに届きます。

**送る情報**

- あなたが選んだ日の、行動履歴(詳しくは、下の「行動履歴について」をご覧ください)
- あなたが選んだ、Xの投稿、ひとこと、日記
- あなたが選んだ、写真
- 「AIに追加で伝えたいこと」に書いた内容
- 書き方や文字数などの設定

選んでいない情報は、送りません。

**行動履歴について**

行動履歴は、位置情報から作った、あなたの行動の記録です。「AIに日記を書いてもらう」で、行動履歴を選んだときは、選んだ日の、次の内容を送ります。

- 滞在した時間帯
- 滞在した場所の名前や住所(あなたが入力した名前、座標から調べた住所、周辺の施設から推定した名前)。住所などが分からないときは、緯度と経度(約10メートルの精度)を、そのまま送ります
- 移動した時間帯、移動の手段、移動した距離(移動の説明を書いたときは、その文章)
- 行動履歴を記録していなかった時間帯

自宅や職場など、普段いる場所も、選んだ日に含まれていれば、その場所の名前や住所が送られます。

**住所などを、AIに送りたくないときは、その日の行動履歴を、選ばないでください。**場所の名前は、行動履歴の画面で書き換えられます。書き換えると、書き換えた名前(「自宅」など)が送られます。

選ばなかった日の行動履歴は、送りません。

**送り先**

あなたが選んだAIのサービスです。どちらも、アメリカなど、日本の外にあるサーバーで処理されることがあります。

- **Gemini**(Google):送った内容は、Googleのサービスの改善に使われることがあります(無料の利用枠で使っているため)。
- **GPT**(OpenAI):送った内容は、OpenAIのモデルの学習には使われません。不正利用の確認のため、最長30日間、保存されることがあります。

これらの扱いは、各社の規約によって変わることがあります。詳しくは、各社のプライバシーポリシーや利用規約をご確認ください。

**写真について**

選んだ写真は、AIに送るために、いったん開発者のサーバー(Amazon Web Services)にアップロードし、AIでの処理が終わったあとに削除します。

**ご注意**

住所や書類など、個人情報が写っている写真や、他の人の個人情報は、選ばないでください。送った内容は、取り消せません。

## 5. 開発者のサーバーに保存する情報

本アプリは、開発者のサーバー(Amazon Web Services)に、次の情報を保存します。

- **端末の匿名のID**:アプリを入れた端末ごとに、アプリが自動で作る番号です。氏名や電話番号などとは結びつけていません。AIの利用量の管理や、お問い合わせの返信のために使います。
- **AIの利用量**:月ごとのトークンの使用量や、残高です。
- **お問い合わせの内容**:お問い合わせに書いた文章、種類、アプリのバージョン、端末の種類(Androidなど)です。不具合の調査と、返信のために使います。
- **通知の宛先**:お問い合わせへの返信を通知するための、端末の通知用のトークンです。お問い合わせを送った端末だけが、登録します。
- **Webのアカウントとの紐づけ**:ポイント・トークンを使うために、Webのアカウントと紐づけたときの、紐づけの情報です。
- **動作の記録(ログ)**:不具合の調査や、使いすぎの防止のために、利用したAIの種類、トークンの数、エラーの種類などを記録します。日記や投稿の本文は、記録しないようにしています。

## 6. そのほかの外部サービス

本アプリは、次のサービスを使います。それぞれ、あなたの端末から、直接アクセスします。

- **地図(OpenStreetMap)**:地図を表示するために、地図の画像を取得します。このとき、表示している地域や、通信の情報(IPアドレスなど)が、相手に伝わります。
- **場所の名前の検索**:行動履歴の場所の名前を調べるために、端末の機能(Androidでは、Googleの機能。iOSでは、Appleの機能)で、座標から地名を調べます。また、近くの施設の名前を調べるために、OpenStreetMapの公開サーバー(Overpass API)に、滞在した場所の座標を送ります。
- **広告(Google AdMob)**:本アプリは、広告を表示します。広告を配信するために、Googleが、広告ID(端末の広告用の番号)などを取得することがあります。広告のパーソナライズは、端末の設定から、オフにできます。
- **通知(Firebase Cloud Messaging)**:お問い合わせへの返信の通知のために使います。

これらのうち、地図、場所の名前の検索、広告などは、あなたが個別に操作しなくても、本アプリの機能を動かすために、自動で通信します。送られる情報は、上に書いたものだけです。日記・ひとこと・写真は、送りません。

これらのサービスは、各社のプライバシーポリシーに従って、情報を扱います。

## 7. 第三者への提供

次の場合を除き、あなたの情報を、第三者に提供しません。

- あなたの同意がある場合(「AIに日記を書いてもらう」「振り返りを作成する」などを、あなたが操作して実行した場合を含みます)
- 法令にもとづく場合

## 8. 情報の削除について

- 端末の中の情報は、アプリの中から削除したり、アプリを削除したりすると、消えます。
- 開発者のサーバーに保存した、お問い合わせの内容などの削除をご希望のときは、「9. お問い合わせ」から、ご連絡ください。端末の匿名のIDなど、お問い合わせの内容から、あなたの情報を特定できる範囲で、対応します。

## 9. お問い合わせ

本ポリシーや、情報の扱いについてのお問い合わせは、アプリの「設定」の「お問い合わせ」から、お送りください。

## 10. 変更について

本ポリシーは、必要に応じて、見直すことがあります。重要な変更があるときは、アプリの中などで、お知らせします。
